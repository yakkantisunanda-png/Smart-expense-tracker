# Smart Expense Tracker + Fraud Detector

A simple Python tool to track daily expenses and detect suspicious high-value transactions.

## Inspiration
This project is inspired by a real NCRP cyber fraud case where Rs. 4169 was earmarked for refund. So I added a fraud alert feature.

## Features
- Add daily expenses with date
- Auto fraud alert if amount > Rs. 4000
- Saves data to CSV file
- Shows all expenses

## How to Run
python expense_tracker.py
